# 黎曼猜想

> 素数在数轴上的分布，由复平面上一条"临界线"上的零点完全决定。

## 背景

素数看似杂乱无章，但其整体分布由黎曼 ζ 函数

```
ζ(s) = Σ n^(-s)
```

的解析性质刻画。黎曼在 1859 年观察到：若 ζ(s) 的**所有非平凡零点**的实部都等于 1/2（即落在临界线 Re(s) = 1/2 上），那么素数的分布误差项将达到理论上的最小可能。

## 问题陈述

**证明或证伪：黎曼 ζ 函数的所有非平凡零点都满足 Re(s) = 1/2。**

## 为什么重要

它是解析数论的"大统一"猜想。上千个定理以"假设黎曼猜想成立"为前提；它直接控制素数定理的误差项、素数间隙等核心问题。

## 现状

悬赏 100 万美元，也是最古老、最著名的未解猜想之一。已用计算机验证前 10¹³ 个零点均在临界线上，但要对**无穷多个**零点给出证明，仍遥遥无期。
