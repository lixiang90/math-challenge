# 伯奇和斯温纳顿-戴尔猜想（BSD 猜想）

> 一条椭圆曲线上有多少个有理数点，由它的 L 函数在 s = 1 处的零点阶数完全决定。

## 背景

椭圆曲线是形如 y² = x³ + Ax + B 的方程定义的曲线，在数论与密码学中至关重要。BSD 猜想把曲线上有理点（莫德尔-韦伊群）的结构，与对应 L 函数的解析性质联系起来。

## 问题陈述

对一条定义在有理数域 ℚ 上的椭圆曲线 E，其 L 函数 L(E, s) 在 s = 1 处的零点阶数 r，等于 E 上有理点群 E(ℚ) 的秩（即独立生成元的个数）：

```
rank E(ℚ) = ord_{s=1} L(E, s)
```

## 为什么重要

它是算术几何与现代数论（尤其是与费马大定理同源的椭圆曲线理论）的核心，也是理解有理数点分布规律的关键。

## 现状

悬赏 100 万美元，未解。特殊情形（如秩 ≤ 1）已被证明；整体猜想仍开放。
